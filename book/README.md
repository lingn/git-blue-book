# Git 技术蓝皮书

从零理解 Git 的工作原理，独立处理日常开发、团队协作、回滚与恢复。

很多 Git 教程从命令开始：先输入 `git init`，再输入 `git add`。读者可以暂时跟着做，却很难回答更重要的问题：文件现在处于什么状态？这个命令会改变哪里？提交已经推送后为什么不能随便改写？发生冲突时 Git 到底在比较什么？

本书采用另一条路线：先建立工作模型，再引入命令。你不会在某一页突然遇到尚未解释的 `HEAD`、暂存区、引用、变基或远程跟踪分支。每个概念都会在需要它之前出现，每条命令都会说明作用对象、影响范围和恢复办法。基础教程之后，书中还会进入远程认证、CI/CD、规模优化、安全、取证、迁移和组织治理。

## 适合谁

- 第一次系统学习 Git 的开发者
- 会用 `add`、`commit`、`push`，但遇到异常场景仍依赖搜索的开发者
- 需要处理冲突、回滚、补丁迁移和发布分支的团队成员
- 希望理解 Git 底层模型，而不是背诵命令的人

## 读完以后

你应该能够先判断问题属于工作区、暂存区、本地历史还是远程历史，再选择操作；能够安全地修改未公开历史，对已经公开的历史使用团队友好的恢复方式；也能够借助引用日志找回大多数“看起来丢失”的提交。
