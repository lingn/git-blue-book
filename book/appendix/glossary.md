# 术语表

术语表用于回看，不承担首次教学。正文第一次使用每个术语时，仍会先给出普通语言解释和工作定义。

| 术语 | 暂定工作定义 |
| --- | --- |
| 仓库 | Git 保存项目历史和相关元数据的地方 |
| 工作区 | 当前可以直接查看和编辑的项目文件 |
| 暂存区 | 为下一次提交挑选内容的中间区域 |
| 提交 | 对一组项目内容和相关信息的不可变记录 |
| 分支 | 指向某个提交、并会随新提交向前移动的名字 |
| `HEAD` | Git 用来表示当前工作位置的特殊引用 |
| 远程仓库 | 通过网络访问、用于交换提交和引用的另一个仓库 |

本页会随正文写作持续补充，并链接到术语首次完整解释的位置。
