# 资料来源与版本说明

## 本书验证基线

- 最低命令主线：Git 2.28；
- 首版实验验证环境：Git 2.49.0；
- 示例 Shell：Bash；
- 远程实验：本地 bare 仓库，不需要网络和平台账号。

本书不把 GitHub、GitLab 等平台界面当作 Git 本身。受保护分支、评审和持续集成属于平台与团队流程，具体配置应参考所用平台当前官方文档。
