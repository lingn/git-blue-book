# 第十篇：安全、签名与供应链

Git 的内容寻址能够发现对象字节是否变化，传输认证能够回答“谁在访问仓库”，但两者都不能单独回答“谁认可了这个对象”“这个人当时是否有权认可”“进入生产的是否就是被认可的内容”。安全体系必须把对象、密钥、权限、评审、构建和审计分层处理。

进入本篇前，读者应理解对象 ID、commit 与附注 tag、远程认证、受保护引用和 CI/CD 证据链。本篇不把某家托管平台的绿色徽章当作通用语义，也不把一次本地密码学验证扩大为供应链安全结论。
