# 安装 Git，并确认当前版本

## 先确认，不要先安装

很多开发环境已经包含 Git。重复安装可能让电脑上出现多个版本，终端实际调用的版本也未必是刚安装的那个。

打开终端，输入本书第一条命令：

```bash
git --version
```

这里：

- `git` 是要运行的程序；
- `--version` 是一个选项，要求程序只报告版本并退出；
- 命令中的空格用于分隔程序名和选项。

如果已经安装，会看到类似输出：

```text
git version 2.49.0
```

你的版本号不需要与示例一致。本书以 Git 2.23 之后提供的 `switch` 和 `restore` 为主线；如果版本更旧，建议先升级。后面遇到与版本有关的行为时会单独标明。

## 没有安装时怎么办

如果终端提示找不到 `git`，请使用系统可信的软件来源：

- Windows：安装 Git for Windows，安装后可以使用 Git Bash 或系统终端；
- macOS：可以安装 Xcode Command Line Tools，或通过你已经使用的软件包管理器安装；
- Linux：使用发行版的软件包管理器安装名为 `git` 的软件包。

安装完成后关闭并重新打开终端，再次执行 `git --version`。重新打开终端是为了让环境变量更新生效。

## 终端中的帮助

查看 Git 的概览帮助：

```bash
git help
```

查看某个命令的简短用法，可以在命令后加 `-h`：

```bash
git config -h
```

这里提前看到了 `config` 这个名字，不要求你现在理解它。下一章会正式介绍。简短帮助直接显示在终端；完整手册通常使用 `git help <命令名>` 打开，退出帮助页面一般按 `q`。

## 常见问题

### 图形客户端里能用，终端却找不到 Git

图形客户端可能自带 Git，但没有把它加入系统命令搜索路径。先查该客户端的设置，或者单独安装系统可用的 Git。不要在不知道来源的情况下从网络复制修改环境变量的命令。

### 输出的版本不是刚安装的版本

这通常说明系统能找到多个 Git。先记录当前现象，不必为了本书立刻删除任何版本。后续排查时应确认终端实际找到的可执行文件位置；不同系统的查询方式不同，因此不在这里提前引入额外命令。

## 动手试试

执行 `git --version`，记下版本。再执行 `git help`，确认你能看到命令列表并返回终端。到这里我们只读取环境，没有修改任何项目或配置。
