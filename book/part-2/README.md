# 第二篇：完成第一次可靠提交

这一篇把第一篇的模型落到本机操作中。每个命令第一次出现时都会解释参数、作用对象和执行后的状态变化。

计划章节：

1. 安装 Git，并确认你正在使用哪个版本
2. 配置身份：提交记录为什么需要作者信息
3. 创建第一个仓库：`git init`
4. 先观察再操作：`git status`
5. 工作区与暂存区：为什么提交前还有一步
6. 选择要进入历史的内容：`git add`
7. 生成第一个提交：`git commit`
8. 看清改了什么：`git diff`
9. 阅读已有历史：`git log` 与 `git show`
10. 不该进入仓库的文件：`.gitignore`

篇末综合场景：把一组混合改动拆成两个语义清晰、可验证的提交。
