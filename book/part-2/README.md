# 第二篇：完成第一次可靠提交

这一篇把第一篇的模型落到本机操作中。每个命令第一次出现时都会解释它接收什么、改变哪里，以及怎样确认结果。

## 本篇内容

1. [安装 Git，并确认当前版本](01-install.md)
2. [配置身份与 Git 配置：记录者不是登录者](02-identity.md)
3. [创建第一个仓库：git init](03-init.md)
4. [先观察再操作：git status](04-status.md)
5. [工作区、暂存区与提交](05-three-areas.md)
6. [选择下次提交的内容：git add](06-add.md)
7. [生成提交：把已审查的 index 写进本地历史](07-commit.md)
8. [看清改了什么：git diff](08-diff.md)
9. [阅读历史：git log 与 git show](09-history.md)
10. [不该进入仓库的文件：.gitignore](10-ignore.md)
11. [综合场景：把混合改动拆成可靠提交](exercise.md)

本篇实验都在一个名为 `git-first-lab` 的练习目录中进行。请不要在真实项目里照抄实验命令。
