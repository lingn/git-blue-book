# 第六篇：把 Git 用进真实工程

这一篇不再增加大量命令，而是组合前面已经掌握的模型和工具，解决工作中频繁出现的完整场景。

计划章节：

1. 工作做到一半需要切任务：`git stash`
2. 同时维护多个工作目录：`git worktree`
3. 定位是哪次提交引入了问题：`git bisect`
4. 查找一行代码和一段逻辑的演变
5. 热修复如何在多个分支之间迁移
6. 发布分支、标签与回滚策略
7. 冲突解决后，如何向同事准确说明冲突点
8. 提交信息、提交粒度与可审查历史
9. 受保护分支和团队协作约定
10. 一套先观察、再行动、可恢复的 Git 排障流程

篇末综合场景：从线上缺陷定位到热修复、评审、发布、回滚预案和事后记录。
