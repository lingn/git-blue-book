# 易变事实登记表

本表记录正文中依赖版本、权限、套餐、计费或厂商实现的事实。Git 的稳定核心语义仍在各章来源中记录；平台界面文案和操作路径不得只靠截图长期保存。

## 登记字段

| 字段 | 要求 |
| --- | --- |
| 事实 ID | 稳定短名，供正文和审校记录引用 |
| 主题 | 认证、评审、CI、审计、LFS、计费等 |
| 厂商与产品 | 写明云服务、自托管版和产品层级 |
| 事实陈述 | 可核对的单一断言，不混合多个条件 |
| 版本或套餐 | 最低版本、许可层级或“不适用” |
| 权限 | 执行或查看该能力所需角色 |
| 计费影响 | 无、包含、按量或需要另行核对 |
| 核对日期 | `YYYY-MM-DD` |
| 官方来源 | 官方文档或发布说明链接 |
| 正文位置 | 使用该事实的章节 |
| 状态 | 待核对、有效、已变化、已移除 |
